# Multiplayer Center package

Use the Multiplayer Center package to get started building a multiplayer game based on a list of available game genre.

Select the game genre you want to learn more about and start iterating on gamplay mechanics with our provided Getting Started samples, recommended packages, and tutorials.

## Install 

To install this package, refer to [Install a package from a registry](https://docs.unity3d.com/Manual/upm-ui-install.html).
