# Multiplayer Center

The Multiplayer Center provides a starting point to create a multiplayer game. It recommends Unity multiplayer packages based on the needs of your game, and gives you access to samples and tutorials to help you use them.

## Get started with a basic sample

1. Open the Unity Multiplayer Center window, go to **Window** > **Multiplayer** > **Multiplayer Center**.
2. Select a game genre that corresponds to your current project.
3. In the **Getting Started** tab, navigate to the **Start by experimenting with a basic sample** section
4. Select **Import** to add the sample to your project.
5. The sample automatically adds all essential packages for multiplayer development with the selected genre as dependencies to your project.

## Install essential and recommended packages

To install the packages that the Multiplayer Center recommends:

1. Open the Multiplayer Center window, go to **Window** > **Multiplayer** > **Multiplayer Center**.
    1. If you have not already, select the game genre that fits your current project.
2. Select the **Getting Started** panel.
3. Select **Install All** in the **Essentials** or **Recommended** sections to install all packages in that section.

The Essentials section includes packages that are core to multiplayer development for the selected game genre.
You must install all packages in the Essentials section to create a multiplayer game with the selected genre.

The Recommended section includes packages that are recommended for the selected game genre.
Packages in the Recommended section are optional, but help your development with additional tools and learning resources, such as multiplayer debugging tools.

To install an individual package:

1. Select the **Open Package Manager** icon next to the package you want to install.
2. In the Package Manager window that appears, select **Install**.

## Get further with the Multiplayer Center

Many installed multiplayer packages include their own tutorials and samples.
The Multiplayer Center lists these resources in categories on the left panel, which updates based on the packages installed in your project.
